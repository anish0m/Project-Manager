# **Project Manager**

A minimalist, high-productivity application designed for organized project tracking and task management. This project focuses on complex state lifting, managing arrays of objects, and handling conditional component views.

## **🚀 Features**

* **Comprehensive Project Creation:** Easily add new projects with specific titles, detailed descriptions, and targeted due dates.  
* **Granular Task Management:** Add and clear individual tasks within each project to track progress at a micro level.  
* **Persistent Sidebar Navigation:** A dedicated "Your Projects" sidebar allows for quick toggling between active initiatives and the project creation interface.  
* **Dynamic Content Views:** Features a smart fallback screen for when no project is selected, guiding the user to start a new entry.  
* **Project Lifecycle Control:** Includes functionality to permanently delete projects once they are completed or no longer needed.

## **🛠️ Technologies Used**

* **Frontend:** React (demonstrated through the "Learning React" use case) / HTML5 & CSS3.  
* **Logic:** JavaScript (ES6+) for managing multi-level state objects and date handling.  
* **Styling:** Custom CSS featuring a professional monochromatic palette, bold typography, and a modern high-contrast layout.
